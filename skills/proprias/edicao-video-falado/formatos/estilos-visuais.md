# Estilos visuais

Três estilos aprovados e um meio-termo. O perfil do criador escolhe o seu; troque as cores no `:root` do `tpl.html`.

## Terminal Noir (série técnica, demos, bancada)

| Token | Cor | Uso |
|---|---|---|
| fundo | `#0B0D10` | tela, tela final |
| janela | `#14171C` | painéis, cards |
| linha | `#2A2F37` | bordas |
| menta | `#5EEAD4` | destaque da legenda, kicker, ícones |
| texto | `#E8EAED` | texto principal |
| sub | `#AAB2BC` / dim `#6B7480` | texto secundário |
| vermelho | `#F87171` | erro, riscado |

Montserrat (títulos e legenda) + JetBrains Mono (kickers, selos, terminal). Legenda palavra a palavra com palavra-chave
em menta. Só SFX, sem música. Partes de no máximo ~85 s.

## Giro amarelo (notícias)

| Token | Cor | Uso |
|---|---|---|
| amarelo | `#FFE500` | palavra-chave da legenda, tags, marca-texto (66% em multiply), data do print |
| tinta | `#0B0D10` | texto sobre o amarelo, ícones |
| janela | `#101318` / linha `#262B33` | faixa do print |
| fundo | `#060709` | tela final, piso do estúdio |
| clima por notícia | alerta `#FF3B4E`, violeta `#C084FC`, energia `#38BDF8`, âmbar `#FFB020`, apocalipse `#FF2D55`, marca `#5EEAD4` | borda/brilho dos prints e tags, fitas de LED |

Legenda Montserrat 800 em caixa alta, branca com contorno preto. Ícones SVG no lugar de emoji.

## Clean Luxury (loja, moda, beleza)

| Token | Cor |
|---|---|
| champanhe | `#EDD3A0` (escuro `#B8935A`) |
| creme | `#F6F1EA` |
| tinta | `#1D1815` |
| sub | `#5D5047` |

Montserrat Bold branca com sombra suave, destaque champanhe; imagem clara e fiel às cores.

## Meio-termo (collab entre um perfil técnico e um de loja)

Cards escuros com kicker mono menta (Terminal Noir) + creme/champanhe e legenda branca (Clean Luxury); a cor do rótulo
de quem fala diz de quem é a fala.
