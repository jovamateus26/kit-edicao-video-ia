# Formatos de vídeo

Cada formato é uma receita testada em vídeo publicado: layout, ritmo, cores e o modelo de código em `../modelos/`.
O perfil do criador (`perfil.md`) diz qual é o padrão dele; se o pedido não disser, use o padrão do perfil.
Se nada disser, pergunte mostrando as opções desta tabela.

| Formato | Quando usar | Material | Modelo |
|---|---|---|---|
| [Giro de notícias](giro-noticias.md) | resumo de 3–6 notícias do dia, 60–90 s. **Padrão atual para notícia** | celular (1 ou vários arquivos) | `modelos/giro-noticias/` (completo) |
| [Notícia com prova](noticia-com-prova.md) | uma notícia só, curta, com prints em split | celular | `modelos/noticia-com-prova/` |
| [App + resultado](app-resultado.md) | demo de app/ferramenta, antes/depois, pouco motion | celular + gravação de tela | `modelos/app-resultado/` |
| [Loop + split](loop-split.md) | demo que abre na prova e emenda o fim no começo | celular + gravação de tela | `modelos/loop-split/` |
| [Bancada narrada](bancada-narrada.md) | celular filmando a mão na massa + voz, selfie no fim | vários clipes curtos | `modelos/bancada-narrada/` |
| [Entrevista game show](entrevista-game-show.md) | perguntas e respostas entre duas pessoas, bem-humorado | celular na mão de quem pergunta | `modelos/entrevista-game-show/` |
| [Loja / moda Clean Luxury](moda-clean-luxury.md) | vendas, novidades de loja, moda, beleza | câmera frontal | `modelos/moda-clean-luxury/` |

Paletas e tipografia de cada estilo: [estilos-visuais.md](estilos-visuais.md).

Regras que valem para todos: `../SKILL.md` (um vídeo só, limpeza da fala, nada sobre rosto/legenda, −14 LUFS).
